Prototype local : ~/mnemosyne-prototype/
README.txt explique l'ouverture, le calcul et les vérifications. Le serveur indiqué dans cet ancien README n'a pas été vérifié vivant pendant la passation. index.html peut être consulté directement ; scripts/serve.py permet de relancer un serveur si nécessaire. Ne pas relancer une expérience simplement pour reprendre le contexte.

Le dossier documentaire comprend trois images, 22 observations provisoires et six propositions comparées. data/corpus.json, observations.json et comparisons.json conservent provenances et limites. Ces relevés ont été produits par des assistants informés des sujets et ne constituent pas une annotation indépendante ou aveugle. Le faible détail de l'image Apollon limite les contacts fins.

Le calcul a réellement été effectué : DINOv2, recherche par patches avec pyramide spatiale, comparaison gradient-NCC, puis évaluation séparée et contrôles de boîtes. La région source est fournie dans cv/inputs.json. Les localisateurs ne lisent pas les références cibles ; cela ne rend pas aveugle la conception du dispositif. Un rejeu isolé DINO a reproduit les15propositions ; ce n'est pas une preuve de généralisation.

Valeurs relues dans cv/evaluation.json lors de la passation :
— Apollon : premier candidat DINO IoU0,706678 ; gradients0,179607 ; boîte centrée0,489 (README et contrôles).
— Pâris : premier candidat DINO IoU0,244305, centre hors référence ; gradients0 ; boîte centrée0,097.
Les références sont approximatives, issues du relevé assisté. Le meilleur résultat parmi cinq propositions est un diagnostic après coup, pas le premier choix du modèle. Les scores ne sont pas des probabilités. Le contrôle sur la source fournie n'est pas un troisième exemple indépendant. Deux œuvres cibles ne démontrent pas une capacité générale ni une supériorité de méthode.

Ni l'identité spécifique du motif, ni les mains/contacts, ni l'action, ni une filiation historique, ni G ne sont évalués. Ces résultats ne valident pas le programme intellectuel. Ils restent une base réutilisable pour une tâche documentaire de localisation si celle-ci devient utile.
